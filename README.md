# Utility Cantiere

Utility tecniche da cantiere, progettate mobile-first e offline-first.

## APK senza PC

Ogni push su `main` avvia automaticamente il workflow **Build Android APK**.

Da GitHub su smartphone:
1. apri **Actions**;
2. apri l'ultima esecuzione **Build Android APK**;
3. scarica l'artifact `Utility-Cantiere-v0.01-APK`;
4. estrai lo ZIP e installa `Utility-Cantiere-v0.01.apk`.

L'APK viene generato nel cloud con Capacitor. Nessun Android Studio necessario.

## Moduli

- Allineamento
- Chiavi e bulloneria
- Flange EN/DIN, ASME, JIS
- Tubazioni
- Filettature
- Conversioni
- Tolleranze
- Pesi e geometria

I dati tecnici vengono aggiunti solo dopo validazione della norma e della revisione di riferimento.
